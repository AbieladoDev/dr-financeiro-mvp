# dr-financeiro-mvp

MVP de demonstração do Dr. Financeiro: a empresa envia um formulário para médicos, eles respondem e a empresa devolve a orientação. Front-only (dados no navegador).

```bash
pnpm install
pnpm dev
```

- Painel: http://localhost:3000/login (acesso de demonstração aparece na tela)
- Formulário do médico: http://localhost:3000/formulario
